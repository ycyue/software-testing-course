# 练习与实操作业

可运行的实操练习在 [`practice/`](../practice/README.md)，一条命令完成一次测试动作。本目录给学习者保存**自己的**书面作业，例如需求评审记录、缺陷报告、SQL 验证、Postman 说明、pytest 运行记录和简历草稿。

建议文件名与各章「MiniShop 工作实战」中的路径一致，例如：

- `chapter-04-minishop-requirement-review.md`
- `chapter-12-minishop-sql.md`
- `chapter-16-minishop-pytest.md`
- `chapter-19-minishop-run.md`
- `chapter-21-resume.md`
- `chapter-22-self-check.md`

不要把真实密码、token 或生产地址写进这些文件。参考答案仍以对应 `chapters/` 正文为准。阶段测验在 `chapters/quizzes/`，通过线为 10 题中至少 8 题。
