# 阶段测验 6：项目收口

覆盖第 17、18、19 章。通过线：≥8/10；第 3、6、9 题必过。

1. 测试金字塔想表达什么？接口层 ROI 高是否等于可以取消 Web 冒烟？
2. pytest 绿了，为什么还不能写性能结论？
3. （必过）为什么不能对公网或生产做 JMeter 练习？
4. MiniShop v1.0 订单成功响应里有没有 `status`？没有的话简历能不能写“测通全部订单状态”？
5. qty=10 和 qty=11 在 v1.0 分别应怎样？仓库曾经有过 qty=1 教学桩，现在还要去第 16 章找第二台服务器吗？
6. （必过）本机最近一次 pytest 是多少 passed、多少 xfailed？xfail 对应哪条缺陷？
7. 覆盖矩阵是干什么的？R-SEARCH 当前结果应填什么？
8. 注册成功会不会自动登录？依据哪条规则？
9. （必过）为什么必须写“个人实践项目”？
10. 哪句正确？ A. MiniShop 是某电商公司核心系统 B. 22 passed 现在仍是仓库数字 C. 空搜索失败可以在报告里写成已修复 D. 创建订单 201 含 id、不含 status

## 答案

1. 下层更快更稳，上层更贵。ROI 必须带场景，不能取消 Web 冒烟。
2. 没有约定负载、百分位和资源证据。功能断言不是负载模型。
3. 未授权加压可能造成事故或违法。只在自有或书面授权环境，且本课程未要求你打高并发。
4. 没有。不能写。
5. qty=10 允许，qty=11 拒绝。仓库曾经有过 `/login` + qty=1 桩，现行第 13～16 章已是 `/api/` 与 qty=10/11；不要另找服务器，跟 PRD。
6. 本机审查为 **38 passed, 1 xfailed**。xfail = BUG-001。以你本机 `evidence/pytest-output.txt` 为准。
7. 把每条 PRD 规则对到用例和证据。R-SEARCH 应填失败 / BUG-001。
8. 不会。R-REG：201 无 token。
9. 材料来自课程仓库和个人练习。冒充企业经历是诚信问题，也经不起深挖。
10. D。B 已过时，以本机最新输出为准。
