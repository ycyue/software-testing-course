第 9 章示意图 · HTTP 报文

一次登录 = 你寄出一封信，服务器盖章寄回来

方法、路径、头字段、正文是请求这封信上的格子；状态码是回信信封上的邮戳。200 只说明「信送到了并按协议回了」，不等于业务一定成功。

POST

请求这封信

寄到：/api/login
Host: 127.0.0.1:8765
Content-Type: application/json

信纸（Body）

{ "phone": "13800138000", "password": "<redacted>" }
⇄
401

响应这封回信

结果：未通过认证
Content-Type: application/json
Set-Cookie: （失败时通常没有登录 Cookie）

信纸（Body）

{ "result": "fail" }

页面上的「登录失败」往往只是把这封回信翻译成了人话。

示意图：先看方法、路径、状态码，再看 Body。不要用「GET 不安全、POST 安全」来读这两封信——加密看的是 HTTPS/TLS，不是方法名字。
