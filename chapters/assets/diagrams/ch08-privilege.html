第 8 章示意图 · 三道门

没认出你、同级偷看、员工进经理室，是三道门

MiniShop 的门牌：未认证 401，横向 403，纵向 403。精确语义留到第 9 章。报告里要写清账号、URL 和实际看到的数据。

401

还没证明你是谁

无 Bearer 且无 Cookie minishop_session，访问 GET /api/orders/{id}。只去掉 Authorization、Cookie 还在，MiniShop 仍会认人。

横向 403

认得你，不是你的柜子

用户 B 带自己的 token 读 A 的订单，预期 403。200 才是失效。

纵向 403

认得你，但这是经理室

普通用户打 /api/admin/orders 得到 403。打开 /admin.html 静态页 200 ≠ API 403。

示意图：隐藏菜单 ≠ 权限。静态页 200 ≠ API 403。直接访问接口、换账号、换窗口都要测。只在授权教学账号上做。
