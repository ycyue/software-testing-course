第 12 章示意图 · NULL 不是空字符串

格子里没有值，和格子里放了「空」是两件事

JSON 的 null 进 Python 是 None，进 SQL 常是 NULL。"" 是长度为 0 的字符串。测试要分开。

NULL / None

没有值

字段存在但值为空，或 SQL 里未填。比较时要用 IS NULL，不是 = ''。

空字符串 ""

有值，值是空

键在，内容长度为 0。对手机号通常应判非法。

缺字段

键根本不在

JSON 里没有 qty。get("qty") 也会得到 None，但原因不同。
