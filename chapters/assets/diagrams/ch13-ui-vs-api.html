UI / Web 功能测试

店门

看见登录按钮、label、错误文案「登录失败」、搜索「共 3 件」。

擅长：用户能不能完成操作、页面有没有挡住。

不擅长：把 20 种 qty 非法值点一遍还保持稳定。

接口测试

后厨窗口

直接 POST /api/cart/items {"qty":11}，看 400 和库里有没有写成 11。

擅长：规则、权限、四态输入、可重复。

不擅长：按钮被 CSS 挡住、文案写错、跳转丢了。

示意图：pytest 全绿仍可能首页点不开。页面绿了仍可能接口把库存写成 11。
