购物车是一排格子，每一格是一份字段

多行用 list。一行里的 sku、qty、stock 用 dict。外层再用 dict 包 items，和常见 JSON 一致。

{ "items": [
  { "sku": "SKU-DEMO-001", "qty": 1, "stock": 10 },
  { "sku": "SKU-DEMO-002", "qty": 2, "stock": 5 }
] }

遍历用 for item in items。取字段用 item["qty"]。集合能去重，但不能直接变成标准 JSON 对象。

示意图：缺键不要用 get 当成和 null 同一条用例。函数默认参数不要用 []。
