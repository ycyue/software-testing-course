第 13 章示意图 · JSON 四态

缺字段、null、空字符串、"1" 在 JSON 里合法，在业务里不是同一条用例

MiniShop 购物车 Body。一次只破坏 qty，四格都带 sku。本实现空串和错误类型可能同一句 wrong type qty，记录仍要分开。

缺字段

键不存在

{"sku":"SKU-DEMO-001"}
400 missing qty

null

键在，值是 JSON null

{"sku":"SKU-DEMO-001","qty":null}
400 null qty

空串

长度为 0 的字符串

{"sku":"SKU-DEMO-001","qty":""}
400 wrong type qty

错误类型

看起来像 1，类型是字符串

{"sku":"SKU-DEMO-001","qty":"1"}
400 wrong type qty

示意图：一次只破坏 qty。缺 sku 会先变成 missing sku，不要画成 null qty。别的系统可能把空串当缺省。不要把这四条叠进同一用例。
