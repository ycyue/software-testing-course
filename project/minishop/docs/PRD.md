# MiniShop PRD v1.0

状态：第 19 章基线。仅用于个人软件测试实践。

## 范围

- 注册、登录、商品列表与搜索、购物车数量、创建订单、管理员查看库存与订单 id。
- 本机 HTTP，默认 `http://127.0.0.1:8765`。

## 非范围

- 支付、退款、物流、优惠券、评价。
- 订单状态机：v1.0 **不定义**待支付/已发货等状态名；创建成功只保证返回订单 `id`。
- 正式域名、HTTPS 证书、短信验证码。

## 已确认规则

| ID | 规则 |
| --- | --- |
| R-PHONE | 手机号为 11 位数字且以 1 开头，按字符串存储 |
| R-PASS | 密码 8～16 位，须同时包含字母和数字 |
| R-REG | 未占用的合法手机号 + 合法密码注册返回 201 与 `phone`，**不**返回 `token`，不自动登录。非法手机号或密码 400；手机号已占用 409 |
| R-CART | 已登录用户修改购物车数量时，数量须为正整数，且不得超过该 SKU **当前**可售库存 |
| R-CART-10 | `SKU-DEMO-001` 教学库存为 10 时，`qty=10` 允许，`qty=11` 拒绝 |
| R-AUTH | 登录成功同时返回 JSON `token` 与 `Set-Cookie`（HttpOnly）。后续接口以 `Authorization: Bearer` 为准，Cookie 可并存，不是三选一登录产品 |
| R-ORDER | `POST /api/orders` 成功返回 201 与 `id`，Body **不含** `status`。默认不幂等：两次成功 POST 得到两个 id |
| R-PERM | 用户不得读写他人订单；非管理员不得访问 `/api/admin/*` |
| R-SEARCH | 关键字为空或仅空白时，**不应**把全量商品当成搜索结果（当前实现不符合，见 BUG-001） |
