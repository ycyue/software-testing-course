# MiniShop v1.0 需求评审记录

日期：2026-09-08。个人实践，非正式公司评审。

| 问题 | 结论 | 去向 |
| --- | --- | --- |
| 订单有哪些状态？ | v1.0 不定义状态机，接口不返回 `status` | 写入 PRD 非范围 |
| `qty=10` 是否允许？ | 允许，等于库存 | R-CART-10 |
| 空搜索应怎样？ | 不应展示全量列表 | R-SEARCH；实现未满足 → BUG-001 |
| 登录用 Cookie 还是 Token？ | 同时给出，后续 API 以 Bearer 为准 | R-AUTH |
| 支付何时做？ | 不做 | 非范围 |
| 管理员能改库存吗？ | v1.0 只读库存和订单 id | 范围裁剪 |

待确认（明确推迟，不阻塞 v1.0 测试）：支付渠道、订单取消、库存预占时长。
