# MiniShop v1.0 测试计划摘要

## 范围

PRD v1.0 已列功能。不含支付、状态机、性能压测（第 18 章仅清单）、未授权环境。

## 策略

- 静态：对照 PRD / OpenAPI。
- 动态：Web 冒烟 + 接口（curl/Postman/pytest）+ 授权库 SQL。
- 自动化：`tests/` 中 pytest；空搜索用 xfail 跟踪 BUG-001。
- 性能：不做加压，见第 18 章清单。

## 优先级

P0：登录、商品列表、合法改数量（含 qty=10）、超库存 qty=11、创建订单、未认证 401。  
P1：四态输入、越权、管理员权限、空搜索。  
P2：注册冲突、搜索命中。  
P0～P3 为课程用例约定。

## 入口

- 可运行 `python3 server.py`
- PRD v1.0 已基线
- 教学账号可用

## 出口

- P0 用例执行完毕且无未关闭的 P0 缺陷
- 接口自动化 22 passed + 1 xfailed（已知 BUG-001）
- 测试报告已写
- 订单相关记录不含臆造状态名

## 风险

| 风险 | 应对 |
| --- | --- |
| 空搜索与 PRD 不符 | BUG-001 开放，不假装通过 |
| 单账号打满并发 | 不做性能结论 |
| 每次启动重置库 | 自动化使用独立临时库 |

## 环境

本机 `127.0.0.1`，SQLite，教学密码仅本地。
