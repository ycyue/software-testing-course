# BUG-001 空搜索关键字返回全量商品

- 环境：MiniShop v1.0，`http://127.0.0.1:8765`，构建为本仓库 `project/minishop`
- 日期：2026-09-08
- 严重程度：Major（搜索结果不可信）
- 优先级：P1（课程缺陷优先级示例，不是全球标准）
- 依据：PRD R-SEARCH

## 步骤

1. 不登录，调用 `GET /api/products?keyword=` 或 `keyword` 为若干空格；
2. 观察 Body 中 `items`。

## 预期

按 R-SEARCH，空或仅空白关键字不应展示全量商品（例如 400 或 `items` 为空并提示输入关键字）。

## 实际

HTTP 200，`items` 含三件商品：`SKU-DEMO-001`、`SKU-DEMO-002`、`SKU-DEMO-003`。

## 证据

- 审查 curl 响应含三件商品；
- pytest `test_empty_keyword_should_not_return_all` 标记 xfail / BUG-001。

## 备注

前端搜索框提交空关键字时同样走到该接口。v1.0 保持开放，不在报告里写成已修复。
