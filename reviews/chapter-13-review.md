## 专项审查

### 技术准确性

- REST 被描述为风格而非 JSON 同义词；契约优先于“是否够 REST”；
- JSON 四种形态（缺键 / null / 空串 / 错误类型）区分正确；
- OpenAPI 与 Swagger 工具史区分正确；
- 401/403、Bearer 与 Cookie 层次与第 8、9 章一致；
- POST 创建默认不幂等，与 RFC 9110 及第 9 章一致；
- 一致性核对应到第 12 章 SELECT；
- 订单教学响应只有 `id`，审查 curl 确认 Body 无 `status` 字段。

### JSON / OpenAPI / curl 验证

- 正文 4 个 `json` 代码块均可 `json.loads`；
- 行内 JSON 对象 19 处全部解析成功；
- OpenAPI 片段含 `openapi=3.0.3` 与 `paths./login.post`；
- 本机教学服务 curl：
  - 正确登录 `200` + `Set-Cookie` + `result=ok`；
  - 错误密码 `401`；
  - `qty=1` → `200`；`qty=11` → `400`；
  - 无认证下单 `401`；带 Token 两次下单两个不同 `id`、均为 `201`。

### MiniShop 一致性

- 路径、Token、错误码均标明教学约定；
- 库存规则沿用数量不得超过可售库存；
- 未冻结订单状态名；
- 未把教学服务冒充已上线 MiniShop 后端。

### 安全

- 密码占位符；禁止未授权扫描；
- 越权仅用自己的测试账号。
