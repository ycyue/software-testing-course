## 专项审查

### 技术准确性

- `==` 与 `is`、`None` 用 `is`、整数不用 `is`，与 Python 3.14 对 int 字面量 `is` 的 `SyntaxWarning` 一致；
- 真值表含 `0` / `""` / `[]` / `{}` / `None`；明确 `if qty:` 会漏掉库存 0；
- `True` 是 `int` 子类、`True == 1`，检查 JSON 整数用 `type(x) is int`；
- `dict.get` 无法区分缺键与 `None`，与第 13 章四态一致；
- 可变默认参数 `bucket=[]` 两次调用共用同一列表，已用运行结果证明；
- JSON 转换表与标准库默认行为一致：`null↔None`、`true↔True`、元组编码为数组、`set` 触发 `TypeError`；
- `json.loads('{"qty":11}')` → `int`，`{"qty":11.0}` → `float`；
- 单引号、`True`、末尾逗号均 `JSONDecodeError`；明确禁止 `eval`；
- `python3 -m pip`、`python3 -m venv`、PEP 668 与 Packaging User Guide 一致；不把 uv/Poetry 当必修；
- 未教授 GET/POST 安全神话、Cookie/Session/Token 三选一、P0 全球统一、接口自动化 ROI 永远最高。

### MiniShop 一致性

- 教学规则：数量为正整数且不得超过可售库存；
- SKU、库存 10、超库存 11、`teach-token` 与第 12～14 章一致；
- 路径与响应形状标明教学约定，非正式 OpenAPI；
- 订单只断言有 `id`、无 `status` 字段。

### 安全

- 密码不入库；完整 token 不作为练习输出；
- 禁止 `eval`、禁止 `sudo pip`；
- 文件写入限定练习目录；无 SQL 写操作。
