## 2. 独立求解时用到的冻结事实（先于看答案）

来自 `project/minishop/docs/PRD.md`、`server.py`、`evidence/pytest-output.txt`、种子 JOIN、Postman 集合，**不是**从练习答案抄的：

| 项 | 独立结论 |
| --- | --- |
| 项目性质 | 个人软件测试实践项目 |
| 登录 | `POST /api/login`；无前缀 `/login` 无路由 → 404 |

| 搜索 | 空/空白关键字当前返回全量，BUG-001 仍开放；pytest `37 passed, 1 xfailed` |
| 订单 | 201 + `id`，Body 无 `status`；默认不幂等 |
| 权限 | 他人 `GET /api/orders/{id}` → 403；普通用户 `/api/admin/*` → 403 |
| 认证 | JSON `token` + `Set-Cookie` HttpOnly；后续 API 以 Bearer 为准 |
| 种子 JOIN | Tester A：`SKU-DEMO-001` qty 1 stock 10；`SKU-DEMO-002` qty 2 stock 5 |
| 12.4 教学库 | 3 用户，用户 3 `display_name` NULL → `COUNT(*)=3`，`COUNT(display_name)=2` |
