原文：「四个常见测试级别」：单元/组件、集成、系统、验收

为什么有问题：不会让学生在 MiniShop 上测错（v1.0 无外部系统），但学生若按本章去对 CTFL 4.x 或面试「测试级别有哪些」，会答四个而大纲是五个。正文已有「不同组织的名称和边界可能略有差异」，这句救了它不成 P1，但作为「分类体系章」仍应给对照。
依据：ISTQB CTFL Syllabus v4.0.1（2024-09-15）§2.2.1：「In this syllabus, the following five test levels are described」。
建议修改：保留「职场口语常见四级」，加一句 4.x 对照；MiniShop 只练到组件级判断、应用-存储交互、系统端到端、验收，不虚构系统集成。
推荐替换文本：
> 职场口语常说四级：单元/组件、集成、系统、验收。ISTQB CTFL 4.x 把集成拆成两条：组件集成（组件之间的接口）和系统集成（本系统与外部系统/服务）。MiniShop v1.0 没有外部订单/支付服务，所以本章用「改数量接口与库存是否一致」只作为**教学近似的交互检查**，不要写成已经存在两个微服务。

### 11.2 阶段测验（仅第 3 章相关题）

覆盖文件：`chapters/quizzes/stage-1-foundations.md`。先独立作答，再看文末答案。Q5 主产自第 2 章，本章只挂轴；Q6、Q9-D 直接考本章。

**Q5 冒烟、确认、回归各回答什么问题？**  
独立答案：冒烟：这份构建关不关得上、值不值得开始深入测。确认：这个已报缺陷修没修好。回归：这次改动有没有弄坏别的已测区域。  
教材答案：冒烟：构建能不能开始测。确认：这个缺陷修没修好。回归：改动有没有弄坏别的。  
比较：一致。

**Q6 功能测试和非功能测试的差别？举 MiniShop 各一例。**  
独立答案：功能问结果对不对（正确密码能否进首页；库存 10 时 `qty=11` 应被拒）。非功能问以什么质量完成（搜索是否在约定时间内返回；错误提示是否好懂 / 交互能力）。  
教材答案：同，并指向第 18 章负载细节。  
比较：一致。

**Q9 哪句正确？** A 测试必须等开发全部完成才能开始 B 没有发现缺陷说明质量已经足够 C 需求和设计工作产品可以接受静态测试 D 兼容性就是性能测试的别名  
独立答案：C。A 是禁止的错误绝对化；B 是无缺陷谬论；D 把 3.9 与 3.10 混名。  
教材答案：C。  
比较：一致。

## 12. 初学者理解障碍

【Beginner Friction】开篇「登录到底算哪一种」非常有效，六轴图把抽象变成戳。会卡住的点：

1. 学习目标 9 条 + 场景导入五轴，前两屏像目录（CH03-0007）。
2. 「接口状态码 / 登录 API / 400 / 403 / Body / 令牌 / P95 / pytest / SQL / products.stock / qty_allowed」在第 7 章之前同时出现（CH03-0005，IMG-002/003/004）。
3. 3.6 教「加入购物车」，作业又禁止写加入购物车（CH03-0001）——这是最伤的自相矛盾，学生会以为自己打开了错误的页面。
4. 探索性夹在目的轴和质量目标轴中间，不知道该往哪条轴上贴（CH03-0006）。
5. 「回归候选」vs「回归测试的一部分」用词略飘，可接受。
6. 实操 3-1 在 `practice/run.py --list` 里不存在（书面编号本来就不认），若学生去跑 `practice/run.py 3-1` 会失败。`practice/README.md` 已说明脚本不认这些编号，章内仍可加一句「不要对 3-1 跑 run.py」。

## 13. 岗位能力缺口

【Job Reality Gap】

1. 坐标轴说话方式本身就是一线可用的：日报里说「系统级功能测试，修复后做确认和风险回归」比背 40 个名词有用。面试题 1 的示范接近真实答法。
2. 缺 CTFL 4.x 五级对照、缺 test type 映射，考证/大厂笔试会吃亏（CH03-0002、CH03-0003）。
3. 探索性缺章程/session/debrief 这三个可写进测试计划的词（CH03-0006、CH03-0008）。现场带新人会说「你今天的 charter 是什么、时间盒多长、记在哪」。
4. 兼容性没有「按用户分布做矩阵、写清不测什么」的微型例子（3.9 有原则无表）。初级入职第一周常被扔一张浏览器清单。
5. 冒烟集合用错控件，会让新人在真实 MiniShop 演示时当场卡死（CH03-0001）——这已经不是「岗位视野」，是作业事故。
6. 灰盒处理得体：没有把它吹成第三种官方级别，符合「与其争论名称不如说清观察手段」。
