- 审计员：Global-Agent-08（Employment Readiness / 模拟招聘初级软件测试工程师）
- 日期：2026-09-10
- 问题前缀：G08-000N
- 范围：整套教材是否能把零基础读者变成「入职第一周能干活」的初级测试。对照第 20–22 章、MiniShop 简历证据、`practice/STATUS.md`、市场外包/1–3 年 JD。

## 0. 模拟录用决定

假设候选人声称「已学完本课程，求初级功能/接口测试」。面试官只看仓库、口述、现场 20 分钟，不看证书。

| 岗位 | 决定 | 理由 |
| --- | --- | --- |
| 应届/转行 **Web 功能测试**（0 年，小团队） | **有条件约面** | 需求/用例/缺陷方法在；必须自己交过 4-1/6-1，自己点过 Postman 与 Network，能不背五段讲 BUG-001 |
| **接口测试**（作为能力，非独立测开岗） | **弱通过 / 需带教** | 四态、401/403、pytest 能跑作者套件；不能证明会从空白契约写脚本 |
| **外包/派遣 1–3 年功能测试** | **筛掉或挂笔试** | JD 年限、禅道/Jira 熟练、MySQL 客户端、App/抓包、Excel 用例、支付/状态机，对不上且课程叫他们别硬投——但这类 JD 是初级市场主体 |
| **自动化 / 测开 / 性能** | **不约** | 第三梯队了解即可，判断正确 |
| **校招测开（手写 SQL + 小脚本 + Git）** | **一轮挂** | SQL 能答 SELECT/JOIN；Git 不会协作；现场写 pytest 没练过 |

录用条件（我愿意给 offer 的最低线，课程目前 **不验收**）：

1. `exercises/` 里有自己写的评审、缺陷单、面试口述，不是抄 `BUG-001.md` / 21.4 范文；
2. 能在我电脑打开 Chrome Network 和 Postman，当场发登录、指出 token 头、解释空搜索红灯；
3. 能对 **不是 MiniShop 的** 一页登录表单在 90 秒内列出测试点；
4. 简历不写独立开发、不写公司、不写精通 JMeter/CI，GitHub 是 fork + 自己的提交。

达不到这四条：完课只证明「读过一本诚实的教材」。

## 2. 能力覆盖矩阵

判定口径（招聘官，不是教学评分）：

- **能**：入职第一周给真实任务，能独立交出可复核产物，现场抽查不穿帮。
- **弱**：知道步骤/能在 MiniShop 上复述，换系统或换工具要人带；或只跑过作者产物。
- **不能**：课程未练到可演示，或作者/学生证据都 Incomplete，简历不该写。

「学完以后」= 按正文门槛勾完，**含** 可跳过的书面实操和 Incomplete GUI。这是平均完课生，不是学霸。

| # | 能力（任务要求） | 判定 | 课程证据 | 招聘官注释 |
| --- | --- | --- | --- | --- |
| 1 | 看需求 | **弱** | 第 4 章方法对；4-1 是 📖，`run.py` 不验收文章；仓库 `requirement-review.md` 是教材 | 交了自己的 5 条歧义/遗漏才升「能」。抄 04B 仍是弱 |
| 2 | 写测试用例 | **弱** | 第 5 章等价类/边界真教；5-1 是跑 qty=10/11 **不是写用例**；`docs/test-cases.md` 是作者摘要表 | 入职要的是 Excel/禅道用例库里一条可执行步骤。课程没练「从空白需求写出 20 条并评审」 |

## 3. 市场缺口

对照 2025–2026 公开样本（东软/中软类外包、远程 Web 测试、智联「初级软件测试」、爱测外包内推、猎聘工具清单）。培训机构「手工岗下降 47%、测开暴涨」文案有广告水分，**不采信为统计**；采信的是 JD 行里反复出现的词。

### 3.2 过时 vs 缺失

- **不是过时：** 禅道、Postman、pytest、等价类、缺陷报告、HTTP 语义。这些仍是初级日常。
- **市场已迁、课程未点名：** Apifox（国内大量 JD 与 Postman 并列）、Charles/Fiddler「抓包」、DBeaver/Navicat、XMind、Excel 用例。不是必须新开大章，但 21.3 应写「JD 写 Apifox、你只用过 Postman → 写能使用 Postman，面试说集合可导入 Apifox，不写熟练 Apifox」。
- **课程故意放第三梯队、JD 仍当筛选词：** JMeter、Jenkins、Selenium。第 21 章匹配策略（谨慎投独立负责框架）方向对，缺 ATS 同义词纪律。
- **课程过小、JD 当项目经验：** 支付、物流、优惠券、订单状态机。禁止伪造是对的；后果是 **MiniShop 过不了多数「电商测试 1–3 年」筛**。

### 3.3 培训班话术 vs 本课

本课 **没有**「支付回调效率提升 40%」「精通分布式 JMeter」。这是就业加分。

本课 **有** 另一套话术：结论→原理→场景→示例→边界；人人 qty=11、BUG-001、37 passed / 1 xfailed。面试官见过两个本课毕业生就会识别。见 G08-0002。

`docs/LEARNING.md`「只为面试：第 19–21 章 + 能指着仓库讲清 BUG-001 和 qty=11」把最短路径写成合法学习法。招聘官视角这就是培训班捷径。见 G08-0007。

## 5. MiniShop 是否够简历

**对 0 年转行 / 应届功能测试：够当唯一项目，不够当唯一 intra 证据。**

够的部分（招聘官认可）：

- 真能跑：前后端、SQLite、OpenAPI、pytest 37/1、开放缺陷 BUG-001；
- 有判定：库存 10 允许 / 11 拒绝、注册不发 token、订单无 `status`、越权 403；
- 诚实非范围：无支付、无状态机、无生产压测；
- 闭环形态：PRD → 用例 → 证据 → 缺陷 → 报告 → 简历句。形态是初级要会的。

不够的部分：

- 业务太薄：3 个 SKU、无支付、无状态、无并发、无优惠券；面试「你还测过别的模块吗」会空；
- HTTP/1.0 教学服务器、固定盐哈希、每次重置库：不得写成安全/架构能力（CH19 已警告，第 21 章未落到简历禁令）；
- 产物几乎全是 **作者的**。19-1 验收「文件在 + 基线没被改掉」，明确不是「你测完一个项目」；
- 同课毕业生项目 **完全同构**，无法区分谁真测过。

**结论：** MiniShop 是合格的 **课程实践作品**，不合格的 **独立项目经验**。简历必须写成「课程个人实践 + 我提交的评审/缺陷/本机 pytest」，不能写成「我负责的电商测试项目」。对 1–3 年外包 JD，它几乎不能当匹配项——课程已禁止夸大，这是正确的市场后果，不是教材漏洞；漏洞是第 22 章面试答「能独立完成 MiniShop 这一类小项目」会让学生以为外面还有很多 MiniShop。

## 6. 诚实边界是否反而让学生无法声称「能使用 Postman/DevTools」

**是。这是本课特有的就业悖论，章节 Agent 记成 P2，本报告升 P1。**

三层事实：

1. **作者诚实（应保留）：** `README.md`、`practice/STATUS.md`、第 10/14/18 章可运行性说明：DevTools **面板无截图**、Postman Runner **未点**、JMeter **未跑**。质量标准 §十禁止补假截图。
2. **能力分档不诚实：** 大纲第一梯队含 DevTools、Postman；22.2 必须掌握表把「接口 / Postman」列为应能做到；21.3 **建议写成能使用**，第二梯队才有「若已跑通」门闩，第一梯队没有。
3. **完课闸不检查 GUI：** 19-1、16-1 检查 pytest 数字。10-1/14-1 是 Incomplete。学生可以从不打开 Postman 而「学完」。

招聘官裁决：

- 作者不点 GUI **不等于** 学生不能点。正确教法是：**学生必须交自己的 Runner 结果和 Network 截图，才能写能使用。**
- 现在教材把「作者没点」和「你学完就能写能使用」叠在一起。老实学生会把 Postman 降成了解（面试吃亏）；不老实学生会抄 21.3（现场穿帮）。
- **不要**用假截图修这个洞。**要**把门闩写进 21.3 和结课自检。

JMeter/CI 放「了解」与诚实边界一致，没有这层悖论。问题只打在被标成第一梯队、又没有学生证据闸的 Postman 与 DevTools。
