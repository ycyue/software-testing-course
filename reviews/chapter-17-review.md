## 专项审查

### 技术准确性

- 测试级别与自动化分层分开，与第 3 章“自动化是执行方式”一致；
- 金字塔说明来源为实践模型，明确不是 ISO/ISTQB 比例；禁止背 70/20/10；
- 冰淇淋倒置作为反模式，未贬低一切 UI 自动化；
- 接口优势绑定契约/环境/断言，并列出按钮、文案、布局等反例；
- Playwright auto-wait、多引擎与 pytest 插件与官方文档一致；Selenium 以 WebDriver 生态描述，未宣布淘汰；
- UI 成本落在定位、等待、flaky、错误覆盖范围；
- CI 与 CD 分开；密钥不进 YAML 明文；
- Cookie/Session/Token 未画成金字塔三层；无 GET/POST 安全神话。

### 可运行性

- pytest-html 4.2.0：`pytest -q --html=report.html --self-contained-html` 生成约 32KB 自包含 HTML；
- 两处 Python 示例 `ast.parse` 通过，均标明示例结构；未安装 Playwright 浏览器或 ChromeDriver，未对公网点击；
- YAML 标明非本仓库流水线。

### MiniShop 一致性

- 数量规则仍在接口层；UI 只谈登录按钮与提示；
- 教学路径非正式 OpenAPI；无订单状态名。

### 安全

- 禁止未授权扫描和在 CI 明文写密码；
- 示例 `goto` 仅限本地教学前端。
