## 可落地补丁（给主审查改正文用）

### 1. 第一眼线框（P10-01）

- 目标文件：`chapters/10-chrome-devtools.md`；新图 `chapters/assets/diagrams/ch10-first-look.html`
- 插入位置：`## 10.1 打开 DevTools` 三面板表之后
- 拟写：

打开后先看顶上一排**功能名**，不要追图标坐标。这一眼里只找三块：

1. 顶栏的 **Elements**、**Console**、**Network**（中间可能夹着 Sources、Performance，先忽略）；
2. 点 **Network** 后，请求列表**上方**的 **Preserve log**、**Disable cache**（中文可能是「保留日志」「停用缓存」）；含义见 10.9、10.10，现在只要能勾上；
3. 点列表里的一条，下方或右侧出现 **Headers / Response / Timing**。

找不到勾选框时，先让 DevTools 处于焦点，再用 Command Menu 搜英文功能名。

- 图需求：文件名 `ch10-first-look`；命题「第一眼只看三块：顶栏标签、列表上方两个勾选、点开后的 Headers/Response/Timing」；盒子：① 顶栏 Elements \| Console \| Network ② 工具条 Preserve log / Disable cache ③ 请求列表 Name/Method/Status ④ 点中一行 ⑤ 子标签 Headers / Response / Timing。不要画真实 Chrome 皮肤。

### 2. Elements / Console 各 30 秒（P10-02）

- 目标文件：`chapters/10-chrome-devtools.md`
- 插入位置：`## 10.3 Elements` 末、`## 10.4 Console` 末；逐步操作第 4 步（401 页面图）之后
- 拟写（10.3 末）：

现在就做：检查工具点登录按钮，记下它是 `<button>` 还是可点击的 `<div>`。错误密码提交后，再点页面上的「登录失败」——这条文案是脚本写入的，查看网页源代码里通常没有。标签名写进取证包即可。不要根据临时改通 DOM 写「前端已修复」。

### 3. MiniShop 上怎么看见 Preserve log（P10-03）

- 目标文件：`chapters/10-chrome-devtools.md`
- 插入位置：`## 10.9 Preserve log` 的 SPA 句之后；`## 10.14 MiniShop 登录定位` 第 3 步后
- 拟写：

MiniShop v1.0 登录成功只是把登录区隐藏、商品区显示，**不是整页跳转**。因此即使用户没勾 Preserve log，登录 POST 通常还在列表里。不要据此认为这个开关没用。

要亲眼看到「导航清空列表」：登录后点「后台」进入 `/admin.html`（一次文档导航）。对比未勾选时登录 POST 消失、勾选后还在。把对比写进取证包。若只测登录、不点后台，就写「本次无整页跳转，Preserve log 未改变列表」。

### 5. localhost 限速的预期记法（P10-05）

- 目标文件：`chapters/10-chrome-devtools.md`
- 插入位置：`## 10.15 MiniShop 慢加载定位` 步骤 8 之后
- 拟写：

本机 `127.0.0.1` 上即使开了较慢限速，接口 TTFB 也常常仍然短，被拉长的多半是图片或脚本的 Content Download。这正好说明限速卡的是传输，不是 MiniShop 的算法。记录写「TTFB 短、下载长」即可。不要把限速下的绝对毫秒写成 MiniShop 性能缺陷，也不要编造数据库慢。三条最长的都是文档或接口且 TTFB 仍短，也据实写。

### 6. 开篇只留三个抽屉（P10-06）

- 目标文件：`chapters/10-chrome-devtools.md`
- 替换位置：`## 这一章解决什么问题` 第一、二段
- 拟写：

第 9 章已经能读懂方法、状态码、Header 和 Body。真正排障时，这些字段藏在浏览器里。只会看页面文案，就只能写“登录失败”；打开开发者工具，才能指出是哪一条 POST、什么状态码、有没有 `Set-Cookie`。

本章用 Chrome DevTools 把页面现象还原成证据。先掌握三个抽屉：Elements 看当前页面、Console 看脚本报错、Network 看发出的请求。Preserve log、Disable cache、Copy as cURL 和「慢在等还是慢在下载」放到 Network 里学，不要开篇就当操作清单。目标不是把你培养成前端开发工程师，而是能取证、能判断方向、能把第 6 章的缺陷写清楚。
