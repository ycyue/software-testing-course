# 软件测试课程主控文件

## 项目

《软件测试从零基础到初级测试工程师》

本仓库用于编写、审查、修正和发布整套软件测试教程。课程面向软件测试零基础学习者，以 MiniShop 作为唯一贯穿实践项目。

## 章节制作流程

每一章必须独立执行以下流程：

1. 按主控大纲生成正文。
2. 对照 Quality Standard v1.0 进行 20 项 Definition of Done 审查。
3. 对技术准确性、时效性、代码、SQL、安全和 MiniShop 一致性进行专项检查。
4. 按 100 分标准评分。
5. 对低于 90 分或检查未通过的内容进行修改。
6. 再次审查，达到发布标准后提交到 main 分支。
7. 在 reviews/ 中保留审查记录、问题清单、评分和修正结果。
8. 完成当前章节后，才进入下一章。

## 章节发布标准

- Definition of Done：20/20 为正式发布；18～19 项需修正后发布；17 项及以下不得发布。
- 综合评分：最低 90/100。
- 核心章节目标：95/100。
- 代码、SQL、curl、JSON、pytest 等可运行示例必须验证；伪代码必须明确标注。
- MiniShop 字段、状态、接口和业务规则一旦确定，后续章节不得随意改变。
- 教材中的 MiniShop 只能标注为个人软件测试实践项目，不得伪造成企业工作经历。

## 文件约定

- chapters/：正式章节正文
- reviews/：逐章质量审查和评分记录
- standards/：质量标准、术语和项目规范
- project/：MiniShop 项目材料
- exercises/：练习、答案和实操作业
