# 软件测试课程

《软件测试从零基础到初级测试工程师》是一套面向软件测试零基础学习者的系统教程。

目标：从零基础学习测试思维、需求分析、测试用例、Web 测试、HTTP、DevTools、Linux、SQL、接口测试、Postman、Python、pytest，并完成可展示的 MiniShop 个人软件测试实践项目。

## 每章制作流程

1. 生成章节正文
2. 按 20 项质量门槛审查
3. 按 100 分标准评分
4. 修正所有问题
5. 重新审查并达到至少 90 分
6. 提交正文和审查记录到 main
7. 再进入下一章

## 目录结构

- chapters/：正式章节正文
- reviews/：逐章质量审查、评分和修正记录
- standards/：主控质量标准和项目规范
- docs/：课程大纲、学习路线和项目说明
- project/：MiniShop 项目材料
- exercises/：学习者作业目录（答案在各章正文）

## 项目声明

MiniShop 仅作为个人软件测试实践项目，不冒充企业工作经历。课程中的测试结果、Bug 和项目材料必须能够在仓库中找到对应依据。
